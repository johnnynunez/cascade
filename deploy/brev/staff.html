Build a Claw.

Give a robot a task in OpenClaw. Watch it through the cameras.

A. How this works

PAAI is installed on a remote Brev machine with an RTX PRO 6000 GPU. It also runs on a DGX Spark. The booth computer opens the chat and cameras; the robot simulation runs on the GPU machine.

You use the normal OpenClaw screen. OpenClaw passes your request to the CASCADE robot tools. Those tools inspect the scene and move the arm in NVIDIA Isaac Sim. The Chrome extension shows the live cameras beside the chat.

The arm and kitchen are simulated. Staff show you how to use the chat, then you give the orders.

B. The workflow

  1. Open the chat

    On the booth computer, open the private demo link supplied by the operator. Click Open OpenClaw. Wait for Ready and check that you can type in the message box.

    First time on this computer?

    Open chrome://extensions, turn on Developer mode, then choose Load unpacked and select this checkout’s extensions/chrome folder. See the extension setup for the full steps.

    The public attendee link shows cameras. Use the private demo link for OpenClaw. The operator shares access details privately.

  2. Put the cameras beside it

    In the OpenClaw tab, click the Physical Agentic AI · OpenClaw Demo extension. Click Connect cameras, allow access to the demo host, then choose Side panel.

    Worktop shows objects and destinations. Side shows the lift and release. Kitchen shows the room. Check all three views and wait for Live.

    Click the camera image to see it large. Click again or press Escape to return.

  3. Ask it to look

    Staff can start with: “Ask about the kitchen, then give the arm one task. We will watch what happens.” Type this in OpenClaw and click the send arrow:

    What can you see on the table?

    Wait for the reply and compare it with Worktop. The green cube is an object; the green outline on the counter is a destination. If the description is wrong, ask for a fresh observation before moving.

  4. Give one order

    Name one object and one destination. For example:

    Please put the orange in the open box.
    Could you put the green cube in the green square?

    Use the loose orange near the arm. The box is the shallow wooden tray beside the green zone.

    Use names from the current scene. If an object or destination is unclear, answer the assistant’s clarification before continuing.

    Wait for the tool and the full reply. A pick can take one to two minutes. Send the next movement only after the arm finishes.

  5. Watch and check

    Use Side to check that the object lifts and stays in the gripper. Use Worktop to watch the release and see where it settles. Read the result with the attendee.

    A missed grasp is a failed attempt. Keep an unverified result unverified. A nearby position alone does not prove release inside the destination.

  6. Reset before the next task

    After the current tool finishes, type:

    Let's start over.

    You can also click Reset above the conversation in OpenClaw.

    Keep this chat open while reset runs. A long conversation can delay it.

    Wait for Scene reset and Live in all three camera views. Check that the gripper is empty, the arm is home and the loose objects are back. If reset is not confirmed, read the chat before trying again. A new chat does not reset the kitchen.

    For the next attendee, click + in OpenClaw to start a new session after the reset finishes.

If something goes wrong

A missed grasp or dropped object

Let the tool finish. Read the failure, reset once and inspect. If it keeps missing, return to observation and let the operator check the demo.

A frozen camera

Pause new movement requests. Keep the extension open while it reconnects. Try Reconnect if needed. Check all three views before continuing.

A disconnected chat

Reset is disabled while the chat is disconnected. Return to the private demo page. Click Open OpenClaw again and read the connection check.

An empty reply or generation error

After the active tool finishes, click + at the top left of OpenClaw to start a new session. Ask for a fresh scene image before another movement. A new session does not reset the kitchen.

A reset reply without a reset

After the active tool finishes, send this once:

Please reset the scene.

If it fails, keep the result and have the operator recover the demo.

This version has a small set of prepared objects and skills. Descriptions and grasps can fail, especially for the lemon and unusual arrangements. A chat description does not certify the arm’s home pose or an empty gripper. Camera previews update a few times per second. Check each attempt.
