CASCADE Cascaded Agentic Skill Control with Adaptive Dispatch and Execution

Agentic robots that never say “done” without proof.

CASCADE puts curated, safety-gated robot skills between an LLM and the robot. A chat host such as OpenClaw, Hermes, Claude Code or Codex calls them over MCP; every motion passes the safety harness and reports a confirmed, refuted or unverified postcondition from physics, perception or jaw width.

Run it without a robot Follow one request GitHub

42 safety-gated skills 52 MCP tools 3 possible verdicts MIT licensed

Three verdicts, never two.

A skill's own ok is a claim. CASCADE checks it on a channel the arm does not control.

confirmed

An independent channel (simulator truth, perception or jaw width) measured the effect the skill claimed.

refuted

A measurement contradicts the claim: the skill's ok is downgraded and the claim is kept as self_reported_ok.

unverified

No usable evidence. It is never promoted to success, and an unknown effect blocks task_done(success=true).

CASCADE sees, plans and keeps it safe.

Every skill goes through one entry point, SkillRuntime.execute(), which records before and after frames, applies safety limits and verifies the result.

  • The brain names and boxes the orange, SAM 2.1-L masks it, and depth places it in 3D in the robot's base frame.
  • GraspGen-X proposes 400 gripper poses; score, approach angle, jaw width, reach at carry height and finger clearance filter them.
  • Inverse kinematics (Pinocchio) and a minimum-jerk curve turn the grasp into joint targets.
  • The safety harness checks every sample before it is sent: joint limits and speed, workspace box, table clearance, keep-out zones, e-stop.

In the reposrc/cascade/skills/runtime.py · src/cascade/safety/ · src/cascade/grasping/ · src/cascade/perception/

Fail closed. One failed check aborts the move. An absent or stale map is never treated as free space.

Physics moves the arm.

One line of JSON per sample goes over TCP to the bridge inside Isaac Sim, which sets the angles as joint targets; each joint's PD motor turns the error into torque.

  • PhysX on the GPU by default (Newton optional) moves the arm, the gripper and the orange.
  • Joint angles return with every frame: the next waypoint starts once the arm settles.
  • The same skills drive MuJoCo on a laptop, or a real arm through its driver.

In the reposcripts/isaac_bridge.py (:8611) · src/cascade/control/

Honest status. Isaac Sim 6.2 is the minimum. The real reBot's first motions are still on the onsite bring-up checklist.

Did the orange really end up in the box?

CASCADE does not trust the arm's own ok. It checks channels the arm does not control: simulator ground-truth pose, cameras, gripper width.

  • A kitchen placement needs full footprint containment, measured support, actual jaw release and an advancing window of at least 0.5 simulated seconds.
  • Receipts land in <run>/placement/ with their SHA-256 in the result and the trace.
  • A claimed success that fails the check is reported as a failure.

Step 1 of 7

In depth: 18 blocks in four phases

The README's in-depth figure follows the same request block by block. What each phase does:

  1. From words to a tool call

    Visitor, local LLM, tool call, MCP, CASCADE runtime. The agent side sits inside the OpenShell sandbox.

  2. See the table, decide how to grasp

    Three simulated RGB-D cameras (new frames about three times per second), the brain's box and a SAM 2.1 mask, a 3D point fused into a live world model, and GraspGen-X candidates filtered to one pose: score at least 0.25, within 18° of vertical, fits the 9 cm jaws, reachable also at carry height.

  3. Turn a grasp pose into robot motion

    Five waypoints, inverse kinematics, a minimum-jerk trajectory sampled 30 times per second, the safety gate, JSON over TCP to the bridge, PD control at 120 Hz physics steps.

  4. Check, then answer

    Verify on an independent channel, return the result over MCP, and let the LLM answer.

02Architecture

Decide fast. Act through one door.

Routine commands resolve through a reflex grammar or learned habits before any LLM call, so robot control never waits on model latency. Whatever decides, every skill runs through the same choke point, with the same safety, tracing and verification.

Tier 1 · Reflexagent/reflex.py
A template grammar turns a routine command into a skill plan.
~µs
Tier 2 · Habitruns/experience.json
Experience memory admits a habit at cosine ≥ 0.9 with more wins than losses, matched clause by clause; recipes replace coordinates with perception queries and are re-grounded before any motion.
~ms
Tier 2.5 · Programagent/programs.py
One authoring turn writes a bounded program of registered tool calls; it runs step by step and the first unverified step stops it.
opt-in
Tier 3 · LLMagent/orchestrator.py
Decomposition, a tool loop and an advisor, with the agent's own past frames and verdicts shown as memory.
2–15 s per turn
MCP hostapps/mcp_server.py
OpenClaw, Hermes, Claude Code or Codex: the host's LLM picks tools directly; CASCADE's own tiers are bypassed.
host's own loop

every tier executes through

SkillRuntime.execute(name, args)the only way a skill runs
  1. Bind the armarm= is bound per thread; an unknown arm is an error.
  2. BEFORE frameKeyframe, wrist keyframes and a postcondition snapshot of the target.
  3. RunWorld-model fusion pauses for motion; any exception becomes ok: false; outcome ok | failed | stuck.
  4. VerifyStrongest channel: physics, belief or gripper. A refuted claim downgrades ok.
  5. Envelope + AFTERPer-skill operating envelope, then a fresh AFTER frame once the arm stopped.
  6. Trace + memoryA trace.jsonl row with its tier, and a ⟨frame, action, verdict⟩ memory tuple.

Beyond one arm

Robot identity is not a class hierarchy of arm, duck and humanoid.

A profile declares domains and resources, and the coordinator registers the tools those domains implement: manipulation, locomotion, fastening, passive sensing and read-only spatial domains sit behind one RobotRuntime.execute() boundary, with the same MCP, traces and memory. FleetRuntime routes tasks to separate robot runtimes. Isaac Sim, MuJoCo and hardware drivers are backend adapters behind shared contracts.

The conversation gateway can run as its own process against cascade-robot-service (protocol cascade.robot-runtime/1, opt-in TLS off loopback); every check stays in the robot process. The opt-in whole_body contract composes an arm on a mobile base with disjoint command endpoints: mock only software evidence that refuses every physical mounted composition.

Two boundaries and an independent check.

What OpenShell enforces

verified live on the Spark, 2026-10-11
  1. Credentials never enter the sandbox: the proxy swaps placeholders for real secrets only on matching requests from /usr/local/bin/node.
  2. Per-tool MCP rules: tools/call reset_stop gets 403 policy_denied before CASCADE sees it.
  3. Deny-by-default egress: no internet, no live view, no occupancy bridge.
  4. Observe-only, live: motion lock denies every motion tool within 10 s; emergency_stop and halt_motion can never be denied.
  5. Every unlock expires: 20 min by default, 12 h at most.

What the harness checks

SafeArm motion path, every profile
  • Peak velocity, joint limits, workspace box, table clearance and keep-out zones.
  • Perception watchdog and stop generation.
  • Optional occupancy (nvblox, Warp) and inter-arm link capsules.
  • Camera on top for wrist cameras; contact stop where a profile enables it (enforced on rebot_rs, measured offline only).
  • The carry guard keeps the post-close attachment through lift and transport.
  • vet_pose() rejects candidates statically; planned routes vet their sampled segments before execution.

Honesty rules in code

key decisions, still load-bearing
  • Authority depends on evidence: limits, stop generation and required geometry fail closed.
  • An absent or stale optional map is not evidence of free space.
  • A self-reported ok is a claim; a refuted claim downgrades it.
  • An unavailable postcondition stays unverified, and results name the channel that answered.
  • The pre-motion plausibility critic is advisory; only the harness refuses motion.
  • The tool surface is derived from the built runtime, not declared.
STOP

Stopping never queues. emergency_stop is handled out of band, a host cancel mid-motion freezes the arm, the first Ctrl+C latches the e-stop, and the dashboard STOP works from any browser on the LAN. CASCADE_HIDE_TOOLS=reset_stop makes clearing a stop staff-only.

Scope: OpenShell runs the agent on every Linux launch of scripts/launch.sh and on the real rig; the Spark kitchen installer still uses the host route. A sandboxed OpenClaw agent ran a physics-confirmed pick and verified reset on 2 of 3 fresh Isaac stages (B35). On a live rig, hand-eye extrinsics in camera profiles are placeholders until calibrated on site.

06Perception and grasping

See, localize, grasp, then check.

Perception runs on its own threads and never waits for the brain; motion skills pause fusion. Grasps are planned in the robot's base frame, so camera pose affects visibility, not grasp geometry.

  1. CamerasN RGB-D streams, latest frame only, stale frames dropped.
  2. Brain + SAM 2.1-LThe brain names and boxes objects; SAM masks them and tracks while the brain refreshes.
  3. BeliefStoreLabel, colour, 3D and freshness; the robot's own body is masked out.
  4. LocalizeA base-frame box; an image older than 5 s cannot authorize a grasp.
  5. GraspGen-X400 diffusion samples in the kitchen; required on the Spark, never replaced by analytic grasps there.
  6. select_graspwidth ▸ IK ▸ harness and observed-scene vetoes.
  7. VerifyLift, jaw check, independent postcondition.

08Learning loops

It learns from evidence, never by loosening a guard.

CASCADE improves the advice around the model, not the safety values. A lesson is admitted only from measured, confirmed outcomes, and offered only after it recurs across tasks.

ASPIRE skill notes

agent/aspire.py · scripts/learn_from_runs.py
kitchen route

Re-implements the API surface and the trace → diagnosis → skill-note loop of NVIDIA GEAR's ASPIRE; no ASPIRE package is imported. Between sessions, a failed-then-confirmed retry becomes a guidance note only with matching skill, goal, arm and held-object context, from live kitchen-sim runs with the retry ledger on.

AdmissionPromoted only after it recurs in ≥ 2 distinct tasks. Each Spark launch freezes the note library and serves a hashed LEARNED.md block (top 2 notes, ≤ 2000 bytes).

Harness²

cascade.harnessing · scripts/harness2_improve.py
opt-inCPU tests

Recursive agent harnessing (arXiv:2610.14224) for the built-in agent. A Propose–Probe–Compose step edits the advice text around the model (rules, tool guidance, triggered skills), runs every candidate on the same task on a real CASCADE stack, selects blind and records lessons in a per-family library.

GateAdoption is gated on CASCADE's own verifier. No weights, safety values or configuration change; guidance for six locked tools cannot be edited, and a lint refuses text that would weaken a guard or claim an unverified success. No measured gain is recorded in the repo yet.

Programs tier

agent/programs.py · memory/programs.py
opt-inmock stack

A program is a bounded list (≤ 12 steps) of registered tool calls with labels as parameters and positions only as perception queries, re-grounded before the first motion. Each step is its own execute() call with its own verdict; MCP hosts get list_programs and run_program.

AdmissionAuthored or distilled, one rule: authorship is never evidence. Stored only from a fully confirmed execution, offered only once promoted across ≥ 2 tasks. No Isaac run of run_program yet.

Memory harness

memory/episodic.py · task_memory
on

A planner shown its own history as images plans multi-step tasks better (Vesta). The brain sees up to K = 4 frames of its earlier actions with their physics verdicts beside the current view, so its answer can cite them.

LimitRemembered beliefs can inform the agent but never aim the jaws.

Advisory judge

eval/progress_judge.py · launch.sh --judge
opt-in

A progress judge scores BEFORE/AFTER keyframes off the hot path and is calibrated against the physics postcondition. Offline, the local Qwen judged 72 recorded Isaac picks: no false negatives, but 15 to 19 false positives.

Never a gateREADY, the exit status and proof.json never depend on it; a positive score is not a success detector.
